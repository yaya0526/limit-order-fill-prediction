# v0.2.0 — Robustness and transfer research release

This release turns the original showcase into a broader, auditable research program. R1–R4 are complete; R5 now has a strict licensed-data intake and independent-audit package while remaining honestly marked as empirically incomplete.

## Research additions

- **R1 — rolling-origin robustness:** three non-overlapping chronological test windows, cross-window dispersion, and trading-day block intervals;
- **R2 — coherent time to fill:** a censoring-aware discrete-time hazard model with zero 5/30/60-second monotonicity violations;
- **R3 — decision-aware thresholds:** validation-only 3:1, 1:1, and 1:3 error-cost scenarios with selectivity guardrails;
- **R4 — independent simulation:** four fixed market/queue regimes that record three ranking-transfer regimes and one complete hidden-queue failure;
- **R5 readiness:** provenance and event schemas, an intake validator, venue-reconstruction requirements, frozen evaluation rules, publication boundaries, and independent-audit gates.

## Main conclusions

- 30- and 60-second ranking is more stable than the 5-second task across source windows.
- A single hazard model provides coherent cumulative fill probabilities without a universal performance gain.
- More selective cost-aware policies reduce normalized error cost but materially reduce recall.
- Ranking can transfer between synthetic generators while calibration and decision thresholds fail to transfer.
- Hidden queue priority is a clear counterexample: all three horizons fail the predeclared R4 ranking criterion.
- No result in this release establishes live AAPL execution quality. R5 remains externally blocked until authorized event data and independent audit are available.

## Reproduce and verify

The public, raw-data-free checks are:

```bash
python scripts/check_repository.py
python -m pytest -q
python scripts/demo_results.py
```

The release contains 33 deterministic tests plus machine-readable acceptance and readiness records. Re-running source models requires the separately authorized teaching workbook; real-data R5 work additionally requires licensed exchange events and venue semantics.

## Data and publication boundary

Only code, documentation, schemas, aggregate results, non-sensitive figures, and the earlier public prediction audit artifacts are released. No proprietary exchange messages, entitlements, participant identifiers, or R5 row-level reconstruction outputs are included.

See [`RESULTS.md`](../../RESULTS.md) for the reviewer summary and [`limitations_and_roadmap.md`](../limitations_and_roadmap.md) for the exact evidence boundary.
