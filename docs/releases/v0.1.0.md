# v0.1.0 — Research showcase

The first public research release packages the completed AAPL limit-order fill-probability study into a reviewer-friendly, auditable repository.

## Highlights

- complete numbered notebook workflow from data audit to final explanations;
- frozen held-out results for 5-, 30-, and 60-second fill horizons;
- concise reviewer-facing findings in [`RESULTS.md`](../../RESULTS.md);
- publication-ready technical report, presentation, and figures;
- machine-readable result and policy artifacts;
- Python 3.11 continuous integration and deterministic unit tests;
- raw-data-free repository validation and a one-command result demo;
- explicit provenance, citation, license, limitations, and research roadmap.

## Try the result demo

The following command uses only Python's standard library and the committed metric table:

```bash
python scripts/demo_results.py
```

Use JSON output for downstream inspection:

```bash
python scripts/demo_results.py --json
```

Neither command requires the restricted Excel or order-book history files.

## Verification

```bash
python scripts/check_repository.py
python -m pytest -q
```

On systems with `make`, run the full local verification path with:

```bash
make ci
```

## Evidence boundary

This release demonstrates a research workflow on deterministic synthetic teaching data. It does not establish live AAPL execution quality, profitability, causal market effects, or transfer to another symbol, venue, or period. See [`docs/limitations_and_roadmap.md`](../limitations_and_roadmap.md) for the detailed boundary and prioritized follow-up experiments.
